## Opción 5: Aplicación de búsqueda semántica con bases vectoriales (introducción a IA)
### Contexto:
Una empresa de contenido desea permitir a los usuarios buscar documentos, artículos o publicaciones por "significado" y no solo por palabras clave.
### Reto: 
Integrar una base vectorial (ej. Weaviate, Qdrant o Elasticsearch con embeddings) para crear un motor de búsqueda semántica sobre textos cargados.

### Componentes esperados:
1. Indexado de datos vectorizados
2. Diseño lógico del sistema de consultas
3. Justificación del uso de vectores
4. Prueba de búsqueda y comparación con búsqueda tradicional
